# ❌⭕ Jogo da Velha (Tic-Tac-Toe) - Refatorado

## 🎯 Objetivo do Projeto
Este projeto consiste na refatoração e modernização do clássico **Jogo da Velha (Tic-Tac-Toe)** baseado no tutorial oficial do React. O objetivo principal é evoluir a aplicação original aplicando boas práticas do desenvolvimento Front-end moderno, como **Clean Code**, **componentização**, **Design System modularizado** e **acessibilidade**.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

### Linguagens Base:
- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização com suporte a Variáveis CSS (Design Tokens).
- **JavaScript (ES6+):** Lógica da aplicação e manipulação de estado.

### Ecossistema & Frameworks:
- **[React](https://react.dev/):** Biblioteca principal para construção da interface baseada em componentes.
- **[Vite](https://vitejs.dev/):** Ferramenta de build rápida e moderna para o ambiente de desenvolvimento.
- **[CSS Modules](https://github.com/css-modules/css-modules):** Escopamento local de estilos para evitar conflitos de classes.
- **[Metodologia BEM](https://getbem.com/):** Padronização na nomenclatura de classes CSS (`bloco__elemento--modificador`).
- **[Bootstrap](https://getbootstrap.com/):** Auxílio no layout responsivo e utilitários de interface.
